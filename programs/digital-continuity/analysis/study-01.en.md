## Question and finding

The study reconstructs an adult female fruit-fly brain from electron microscopy: 139,255 neurons and roughly 50 million chemical synapses. Unlike an isolated fragment, this resource permits questions about connections across a whole brain. The author abstract in an institutional record was checked; neurons and synapses were not independently recounted.

## Interpretation

For ORI, the work expands the set of testable models. A proposed processing circuit can now be compared with reconstructed anatomy rather than only a convenient diagram. However, a connectivity graph constrains dynamics; it does not contain the system's complete temporal history. A particular memory or subjective state cannot automatically be inferred from a list of connections.

## Limitations

The biological specimen, image reconstruction and a computational model built upon it are different objects. Segmentation errors and incomplete annotations can affect individual network conclusions despite the impressive overall scale. Extending findings from a fly to a human requires further justification. This entry does not audit the dataset, reproduce analyses or verify individual connections.

## Next research step

A useful test would select a circuit and specify the function to be predicted beforehand. An anatomically constrained model could then be compared with an unconstrained model on new observations. Reporting must identify which parameters were fitted to answers and which followed from anatomy. Such a test would assess the map's explanatory value for function, rather than personal transfer. It is an ORI proposal, not an experiment already conducted here.
