# Когда автономная система должна остановиться

**RU** · [English](README.md)

Оксфордские работы демонстрируют три разные возможности: распознавание ранее посещённого места, передача управления навигацией между камерами и координация нескольких роботов на одном складе. Они не подтверждают, что общая сеть камер безопасно выдержит отказ в масштабе порта. Отдельные работы о мониторинге дорожного покрытия показывают, почему повторные сигналы помогают выбрать места для осмотра. Но повторяемый сигнал сам по себе не подтверждает дефект.
