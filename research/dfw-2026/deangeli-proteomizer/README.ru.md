# Когда модель «РНК → белок» переносится на новые данные?

[English](README.md) · **Русский**

**Исследовательский вопрос:** какие данные показывают, что модель оценки содержания белков человека по данным транскриптомики работает на новой когорте, а не только интерполирует в пределах знакомых данных?

**Вывод ORI:** валидация внутри когорты, дообучение на целевых данных и внешняя проверка модели без изменений отвечают на разные вопросы. Единый коэффициент корреляции может скрыть как утечку между выборками, так и серьёзные ошибки внутри когорты. Для каждого утверждения нужны соответствующие схема разделения данных, сравнение и единица оценки.

- [Атлас доказательств](ATLAS.ru.md): первичные источники, сравнение и ограничения.
- [Чек-лист оценки](RESEARCH-DESIGN.ru.md): что делает утверждение о переносимости обоснованным.
- [Все семь исследований](../README.ru.md).

Границы: неклинический обзор опубликованных работ об уровне белков человека. Без новых экспериментальных результатов, данных отдельных пациентов, молекулярного дизайна и клинических рекомендаций.
